# TradingAgents 从零配置与运行指南

> 本文档以"全新机器、什么都没装"为起点，一步步讲清楚怎么把 TradingAgents 跑起来。
> 如果你已经完成了某一步，直接跳过即可。

---

## 一、前置条件

| 依赖 | 版本要求 | 说明 |
|---|---|---|
| Python | 3.11 或 3.13（推荐） | 3.10 以下不支持 |
| Git | 任意现代版本 | 用于克隆源码 |
| LLM API Key | 至少一个 | 见下文支持清单 |
| （可选）Alpha Vantage Key | 免费申请 | Yahoo Finance 被限速时的备用数据源 |

## 二、获取源码

本工作区已经有源码，位于 `源代码/` 目录，**不需要再克隆**。
如果是在全新机器上从头来过：

```bash
git clone https://github.com/TauricResearch/TradingAgents.git
cd TradingAgents
```

## 三、创建 Python 虚拟环境

### 方式 A：使用 conda（推荐）

```bash
conda create -n tradingagents python=3.13
conda activate tradingagents
```

### 方式 B：使用 venv（标准库自带）

```bash
# 在 源代码/ 目录下执行
python -m venv .venv

# Windows 激活
.venv\Scripts\activate

# Linux / macOS 激活
source .venv/bin/activate
```

## 四、安装依赖

进入 `源代码/` 目录后安装：

```bash
cd 源代码
pip install .
```

安装完成后，会自动注册一个全局命令 `tradingagents`，可以在终端直接调用。

> **注意（Windows 非 ASCII 路径问题）**
> 如果你的虚拟环境路径包含中文（例如位于 `部署/` 目录），CLI 启动时会自动处理 SSL 证书路径问题，无需手动干预。

## 五、配置 API Key

这是最关键的一步。所有敏感配置都放在 `.env` 文件里，**不能提交到 Git**。

### 5.1 选择 LLM 提供商

项目支持以下提供商，**选一个**填入对应 Key 即可：

| 提供商 | 环境变量 | 国内可用？ |
|---|---|---|
| OpenAI（GPT） | `OPENAI_API_KEY` | 需代理 |
| Google（Gemini） | `GOOGLE_API_KEY` | 需代理 |
| Anthropic（Claude） | `ANTHROPIC_API_KEY` | 需代理 |
| DeepSeek | `DEEPSEEK_API_KEY` | ✅ 直连 |
| 阿里云（Qwen 国际版） | `DASHSCOPE_API_KEY` | 需代理 |
| 阿里云（Qwen 国内版） | `DASHSCOPE_CN_API_KEY` | ✅ 直连 |
| 智谱（GLM 国际版） | `ZHIPU_API_KEY` | 需代理 |
| 智谱（GLM 国内版） | `ZHIPU_CN_API_KEY` | ✅ 直连 |
| MiniMax 国际版 | `MINIMAX_API_KEY` | 需代理 |
| MiniMax 国内版 | `MINIMAX_CN_API_KEY` | ✅ 直连 |
| xAI（Grok） | `XAI_API_KEY` | 需代理 |
| OpenRouter | `OPENROUTER_API_KEY` | 看线路 |
| Ollama（本地模型） | 无需 Key | ✅ 本地 |

### 5.2 创建 .env 文件

**以 `部署/` 为工作目录**（推荐使用本工作区封装好的启动脚本）：

```bash
# 在 部署/ 目录下
cp .env.example .env
```

然后用编辑器打开 `部署/.env`，填入你的 Key。

**最简配置（以 DeepSeek 为例）：**

```env
# ==== LLM API Key（只填你要用的那个）====
DEEPSEEK_API_KEY=sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

# ==== LLM 运行时配置 ====
TRADINGAGENTS_LLM_PROVIDER=deepseek
TRADINGAGENTS_DEEP_THINK_LLM=deepseek-reasoner
TRADINGAGENTS_QUICK_THINK_LLM=deepseek-chat
TRADINGAGENTS_LLM_BACKEND_URL=https://api.deepseek.com
TRADINGAGENTS_OUTPUT_LANGUAGE=Chinese

# ==== 运行时数据路径（保持默认即可）====
TRADINGAGENTS_RESULTS_DIR=./data/tradingagents/logs
TRADINGAGENTS_CACHE_DIR=./data/tradingagents/cache
TRADINGAGENTS_MEMORY_LOG_PATH=./data/tradingagents/memory/trading_memory.md
```

> `TRADINGAGENTS_OUTPUT_LANGUAGE` 控制最终报告语言，可以改成 `Chinese` 让输出中文。

### 5.3 可选：配置 Alpha Vantage（数据备援）

Yahoo Finance 在国内经常被限速，建议同时申请一个免费的 Alpha Vantage Key：

- 申请地址：https://www.alphavantage.co/support/#api-key
- 免费版每分钟 5 次、每天 500 次，足够日常使用

在 `.env` 中追加：

```env
ALPHA_VANTAGE_API_KEY=XXXXXXXXXXXXXXXX

# 数据源路由：优先 yfinance，失败后自动切 alpha_vantage
TRADINGAGENTS_CORE_STOCK_VENDOR=yfinance,alpha_vantage
TRADINGAGENTS_GET_STOCK_DATA_VENDOR=yfinance,alpha_vantage
TRADINGAGENTS_GET_NEWS_VENDOR=yfinance,alpha_vantage
TRADINGAGENTS_GET_GLOBAL_NEWS_VENDOR=yfinance,alpha_vantage
TRADINGAGENTS_GET_INSIDER_TRANSACTIONS_VENDOR=yfinance,alpha_vantage
```

## 五补、企业版提供商（Azure OpenAI 等）

如果你使用 Azure OpenAI 或其他企业级接入点，需要单独的配置文件：

```bash
# 在 源代码/ 目录下
cp .env.enterprise.example .env.enterprise
```

编辑 `.env.enterprise`，填入企业凭据：

```env
# Azure OpenAI
AZURE_OPENAI_API_KEY=your_azure_key
AZURE_OPENAI_ENDPOINT=https://your-resource-name.openai.azure.com/
AZURE_OPENAI_DEPLOYMENT_NAME=your_deployment_name
# OPENAI_API_VERSION=2024-10-21  # 可选，非 v1 API 时需要
```

然后在 `.env` 中设置：

```env
TRADINGAGENTS_LLM_PROVIDER=azure
```

## 六、运行程序

### 方式 A：使用封装脚本（推荐，适用于本工作区）

本工作区在 `部署/` 目录下提供了开箱即用的脚本，会自动处理虚拟环境、SSL 证书、路径等问题。

**PowerShell（Windows 推荐）：**

```powershell
# 在 部署/ 目录下执行
# 首次运行，自动创建虚拟环境并安装依赖
.\run-local.ps1 -Install

# 后续直接启动交互式 CLI
.\run-local.ps1

# 启动并分析某只股票（跳过菜单，直接进入分析流程）
.\run-local.ps1 -Analyze

# 启用断点续跑（崩溃后可从上次进度继续）
.\run-local.ps1 -Analyze -Checkpoint
```

**CMD（Windows 备用）：**

```cmd
run-local.cmd
```

### 方式 B：直接用已安装的命令（conda/pip 安装后）

```bash
# 确保虚拟环境已激活
tradingagents          # 启动交互式 CLI

# 或者直接从源码目录运行
cd 源代码
python -m cli.main
```

### 方式 C：Docker（无需本地安装 Python 环境）

```bash
# 在 源代码/ 目录下
cp .env.example .env   # 填入你的 API Key
docker compose run --rm tradingagents
```

如果要同时跑本地 Ollama 模型：

```bash
docker compose --profile ollama run --rm tradingagents-ollama
```

> Docker 方式适合不想折腾 Python 环境的场景，但首次 build 镜像较慢。

### 方式 D：用 Python 脚本编程调用

**最简调用：**

```python
from tradingagents.graph.trading_graph import TradingAgentsGraph
from tradingagents.default_config import DEFAULT_CONFIG

# DEFAULT_CONFIG 会自动读取 .env 中的 TRADINGAGENTS_* 变量
config = DEFAULT_CONFIG.copy()

ta = TradingAgentsGraph(debug=True, config=config)

# 分析 NVDA 在 2024-05-10 这一天的交易决策
_, decision = ta.propagate("NVDA", "2024-05-10")
print(decision)
```

**在代码里硬覆盖配置（优先级高于 .env）：**

```python
from tradingagents.graph.trading_graph import TradingAgentsGraph
from tradingagents.default_config import DEFAULT_CONFIG

config = DEFAULT_CONFIG.copy()

# 指定 LLM 提供商和模型
config["llm_provider"] = "openai"          # 可选：openai, google, anthropic, xai,
                                            #        deepseek, qwen, qwen-cn,
                                            #        glm, glm-cn, minimax, minimax-cn,
                                            #        openrouter, ollama, azure
config["deep_think_llm"] = "gpt-5.4"        # 复杂推理用的大模型
config["quick_think_llm"] = "gpt-5.4-mini" # 快速任务用的小模型

# 辩论与讨论轮数（越高越慢越细致）
config["max_debate_rounds"] = 2
config["max_risk_discuss_rounds"] = 2

# 启用断点续跑
config["checkpoint_enabled"] = True

ta = TradingAgentsGraph(debug=True, config=config)
_, decision = ta.propagate("NVDA", "2026-01-15")
print(decision)
```

**调用后执行反思记忆（可选）：**

```python
# 传入本次持仓的实际收益（正负均可），触发 Agent 反思并写入记忆日志
ta.reflect_and_remember(profit_loss=1000)  # 单位与你的仓位单位一致
```

> `reflect_and_remember()` 会将本次决策的实际结果写回记忆日志，供下次分析时参考。

## 七、交互式 CLI 操作流程

启动后依次选择：

1. **股票代码**：美股直接输入如 `NVDA`、`AAPL`；港股加后缀如 `0700.HK`；A 股目前需要特殊适配（官方尚未原生支持）
2. **分析日期**：格式 `YYYY-MM-DD`，例如 `2024-05-10`
3. **LLM 提供商**：从列表选择，与 `.env` 中配置对应
4. **研究深度**：控制 Agent 辩论轮数，影响质量和耗时
5. **输出语言**：也可以在 `.env` 里预设，这里可以覆盖

## 七补、持久化与记忆系统

TradingAgents 会自动维护两种持久化状态，**无需手动开启**。

### 决策日志（始终开启）

- 每次分析完成后，决策结果自动追加到 `trading_memory.md`（路径由 `TRADINGAGENTS_MEMORY_LOG_PATH` 控制，默认 `~/.tradingagents/memory/trading_memory.md`）
- **下次分析同一只股票时**，系统会：
  1. 拉取该股票上次决策后的实际收益（与基准 SPY 的 alpha）
  2. 生成一段反思文字
  3. 把近期同股票决策 + 跨股票经验教训注入 Portfolio Manager 的 prompt
- 效果：每次分析都能从历史错误中学习，越跑越准
- 本工作区路径：`部署/data/tradingagents/memory/trading_memory.md`

### 断点续跑（opt-in）

- 需要显式开启（`--checkpoint` 或 `config["checkpoint_enabled"] = True`）
- LangGraph 在每个节点执行完成后保存状态到 SQLite 数据库
- 如果程序崩溃或手动中断，下次运行时会从最后成功的节点继续，而不是从头开始
- SQLite 文件位置：`{TRADINGAGENTS_CACHE_DIR}/checkpoints/<TICKER>.db`
  - 本工作区：`部署/data/tradingagents/cache/checkpoints/`
- 运行成功后断点数据库自动清除
- 运行日志提示：
  - `Resuming from step N for <TICKER> on <date>` → 从断点恢复
  - `Starting fresh` → 全新开始

## 八、主要配置参数速查

所有参数在 `源代码/tradingagents/default_config.py` 中定义，可以通过 `.env` 覆盖，**不需要改代码**：

| 环境变量 | 默认值 | 说明 |
|---|---|---|
| `TRADINGAGENTS_LLM_PROVIDER` | `openai` | LLM 提供商 |
| `TRADINGAGENTS_DEEP_THINK_LLM` | `gpt-5.4` | 复杂推理用的大模型 |
| `TRADINGAGENTS_QUICK_THINK_LLM` | `gpt-5.4-mini` | 快速任务用的小模型 |
| `TRADINGAGENTS_LLM_BACKEND_URL` | （各提供商默认） | 自定义 API 端点，用于代理或中转 |
| `TRADINGAGENTS_OUTPUT_LANGUAGE` | `English` | 报告输出语言 |
| `TRADINGAGENTS_MAX_DEBATE_ROUNDS` | `1` | 研究员辩论轮数，越高越慢越细致 |
| `TRADINGAGENTS_MAX_RISK_ROUNDS` | `1` | 风险讨论轮数 |
| `TRADINGAGENTS_CHECKPOINT_ENABLED` | `false` | 是否启用断点续跑 |
| `TRADINGAGENTS_RESULTS_DIR` | `~/.tradingagents/logs` | 分析结果保存目录 |
| `TRADINGAGENTS_CACHE_DIR` | `~/.tradingagents/cache` | 缓存目录（含断点数据库） |
| `TRADINGAGENTS_MEMORY_LOG_PATH` | `~/.tradingagents/memory/trading_memory.md` | 决策记忆日志路径 |

## 九、常见问题

### Q1：Yahoo Finance 报错或数据拿不到

国内访问 Yahoo Finance 容易被限速或封锁。解决方案：
- 配置 Alpha Vantage 作为备用（见第五章 5.3）
- 或者给程序设置 HTTP 代理

### Q2：SSL 错误（`[SSL: CERTIFICATE_VERIFY_FAILED]`）

Windows 下虚拟环境路径包含中文时可能出现。
- 使用 `部署/run-local.ps1` 脚本启动，它会自动处理证书路径
- 或者把虚拟环境迁移到纯英文路径

### Q3：`tradingagents` 命令找不到

说明 pip 安装后的脚本路径不在 PATH 里。
- 确认虚拟环境已激活
- 或者改用 `python -m cli.main`（在 `源代码/` 目录下）

### Q4：如何切换模型？

只需修改 `.env` 中的三行：

```env
TRADINGAGENTS_LLM_PROVIDER=deepseek        # 换成你的提供商
TRADINGAGENTS_DEEP_THINK_LLM=deepseek-reasoner
TRADINGAGENTS_QUICK_THINK_LLM=deepseek-chat
```

不需要改任何 Python 代码。

### Q5：想用 Ollama 本地模型怎么配？

```env
TRADINGAGENTS_LLM_PROVIDER=ollama
TRADINGAGENTS_DEEP_THINK_LLM=qwen2.5:72b   # 你 pull 下来的模型名
TRADINGAGENTS_QUICK_THINK_LLM=qwen2.5:7b
# 如果 Ollama 不在本机，指定远程地址
# OLLAMA_BASE_URL=http://192.168.1.100:11434/v1
```
